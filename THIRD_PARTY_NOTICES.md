covers the main bundled runtime components; it is not a complete software bill
of materials for every build-time dependency.

support. The bundled file retains its upstream notice header.

- Viz.js: `3.24.0`
- Viz.js copyright: Copyright (c) Michael Daines
- Graphviz: https://www.graphviz.org
- Graphviz version reported by bundled runtime: `14.1.1`
- Expat: https://libexpat.github.io

The upstream `viz-global.js` header states that Graphviz and Expat are included
in object code form. Before replacing this vendored runtime with another
distribution, re-check the upstream license notices for Viz.js, Graphviz, and
Expat and update this file if the included object code changes.
