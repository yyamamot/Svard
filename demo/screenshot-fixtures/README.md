# Svard screenshot fixtures

This directory contains synthetic documents for capturing public Svard screenshots.

Use these files when preparing product screenshots for the static site, release notes, or UI review artifacts. Do not add private documents, private paths, unpublished repository URLs, tokens, endpoint URLs, or real customer/project data here.

Recommended flow:

1. Open `demo/screenshot-fixtures/workspace/` in Svard.
2. Capture the needed screen with this synthetic workspace.
3. Export only reviewed screenshots to the site or release artifact location.

The fixture content is intentionally small and public-safe.
