# Product Guide

Svard is a local-first desktop viewer for reading, searching, and comparing technical documents.

## Reading workflow

Use Svard to open AsciiDoc and Markdown files, navigate headings, and keep related documents available in tabs or separate windows.

## Search

Search is available in the current document and across all files in the workspace.

## Diagram rendering

Mermaid, PlantUML, and Graphviz use local rendering as the primary path. Kroki is only an explicit fallback.
