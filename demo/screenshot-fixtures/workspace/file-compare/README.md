# File compare fixtures

Use these two files for screenshots of file-to-file rendered comparison.

Suggested flow:

1. Open `product-guide-a.md`.
2. Use file compare to compare it with `product-guide-b.md`.
3. Capture the rendered comparison view.

The files intentionally differ in:

- product summary wording
- tabs versus separate windows
- current-file search versus all-files search
- fallback-first diagrams versus local-first diagrams
- source comparison versus rendered output comparison
