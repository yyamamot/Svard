# Product Guide

Svard is a desktop viewer for reading local technical documents.

## Reading workflow

Use Svard to open AsciiDoc and Markdown files, navigate headings, and keep related documents available in tabs.

## Search

Search is available in the current document.

## Diagram rendering

Diagrams may be rendered with a configured fallback service when needed.

| Area | Status |
| --- | --- |
| Reader | Ready |
