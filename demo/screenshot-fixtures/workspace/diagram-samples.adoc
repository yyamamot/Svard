== PlantUML sequence

[plantuml]
....
@startuml
actor Reader
participant Svard
participant "Local Renderer" as Renderer
Reader -> Svard: Open diagram document
Svard -> Renderer: Render locally
Renderer --> Svard: SVG result
Svard --> Reader: Display diagram
@enduml
....
